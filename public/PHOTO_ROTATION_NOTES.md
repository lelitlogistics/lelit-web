# Homepage photo rotation

- Hero: 3 Amazon/Rivian exterior images, 10-second interval.
- Operation: 3 operational Rivian images, 10-second interval, 3-second stagger.
- Careers: 3 driver/Rivian images, 10-second interval, 6-second stagger.
- Crossfade: 1.4 seconds.
- Images are preloaded to reduce flashes.
- Rotation pauses while the tab is hidden.
- `prefers-reduced-motion` keeps a single static image.
- Contact/Application component is not modified.

Image sources: Amazon / About Amazon editorial photography.
